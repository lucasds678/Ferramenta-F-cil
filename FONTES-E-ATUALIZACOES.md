# Fontes e plano de atualização — Ferramenta Fácil

Este projeto é estático: HTML, CSS e JavaScript funcionam no navegador, sem banco de dados ou servidor próprio. Os conteúdos educativos locais são uma primeira versão e não representam uma base fiscal completa.

## Fontes oficiais principais
- NCM Classif (Siscomex): https://portalunico.siscomex.gov.br/classif/
- Portal Nacional da NF-e e tabelas: https://www.nfe.fazenda.gov.br/portal/principal.aspx
- CONFAZ: https://www.confaz.fazenda.gov.br/
- Reforma Tributária — Receita Federal: https://www.gov.br/receitafederal/pt-br/acesso-a-informacao/acoes-e-programas/programas-e-atividades/reforma-tributaria-do-consumo
- Portal Nacional da NFS-e: https://www.gov.br/nfse/pt-br
- Portal do Empreendedor: https://www.gov.br/empresas-e-negocios/pt-br/empreendedor

## Processo sugerido para futuras atualizações
1. Baixar tabelas diretamente das fontes oficiais.
2. Registrar a data de download, versão e fonte de cada arquivo.
3. Validar estrutura e conteúdo antes de substituir os dados do site.
4. Separar tabelas oficiais de explicações didáticas próprias.
5. Registrar alterações e testar pesquisas após cada atualização.

## Limites desta versão
- A lista de CFOPs embutida é seletiva, não completa.
- Não há ainda uma tabela completa incorporada de NCM, CEST, CST ou CSOSN.
- O simulador IBS/CBS calcula somente as alíquotas que o visitante informar; não identifica alíquota legal, créditos, compensações ou regime fiscal aplicável.
- O assistente de operação gera um roteiro de conferência, não um parecer fiscal.
- As páginas não substituem orientação contábil nem a consulta da legislação vigente.
